# 当代诗歌审美：展开版

本文件是 SKILL.md 的展开：通感的生成工艺、意象的神经系统、节奏与抒情的细节、正反例、黑名单、声音谱系。所有例句均为本技能自写，供对照手法，不可挪入用户稿件。

## 一、通感与联觉：想象的发动机

通感是把一种感官的经验挪到另一条通道上说出：钱锺书《通感》举过"红杏枝头春意闹"——在视觉里听出了声音；李贺"羲和敲日玻璃声"——太阳被敲出玻璃的声响。联觉更宽：感受在色、温、重、味、嗅、触之间的整体串线。

当代诗的想象力，核心就是这种调动。不是找更华丽的词，而是**找经验在另一条感官通道里的等价物**。机器没有身体，要无限接近，就靠工艺补：每一次转移都要能被读者的身体接住。

**生成工艺：**

1. **感官矩阵。**把核心经验的剖面逐格去想：形 / 色 / 声 / 温 / 味 / 嗅 / 触 / 重量。这种疲惫是什么温度？什么重量？入口是什么味道？填不出的格子留着——空格会逼你去注意细节。
2. **跨通道转移。**横向扫描矩阵，把两条通道焊在一起试写：给声音温度、给颜色重量、给疼一个形状、给沉默一种味道。数量优先，先污染再筛选。
3. **两道检验。**
   - **接得住**：转移能在身体里定位。"安静有金属的味道"落在舌根和鼻腔；"尖锐的蓝色"接不住，只是形容词乱配。
   - **承重**：这次转移对经验说了更真的话。"灯光掉进来，叮的一声，也掉进来"承重——空楼里光与声的同落就是空本身；"手机屏幕幽蓝如深海"不承重，纯装饰。
4. **配额。**8–25 行的诗，真正的转移留一到两处最重的，其余让位给白描与句法。每行都串线，是把通感用成了新的滥调。

**正反例**——主题"深夜加班"。

失败的白描版（不滥调，但只有道具，没有电；意象之间靠"加班"这个主题硬串）：

> 最后一盏灯关掉时，键盘声忽然变得很响。
> 外卖盒里剩两块牛肉，凉了，油凝成一层白的。
> 电梯每一层都停，门开时没有人。只有一楼的风换了口气。

通感驱动版（同一夜，感官在串线：都在降温、变金属、失重）：

> **加班夜**
>
> 十一点四十，中央空调先下班，
> 剩下的安静有一种金属的味道。
> 显示屏的蓝越来越凉，
> 一行行代码从指缝流过去，
> 没有重量。
>
> 电梯每停一层，就有灯光
> 掉进来，叮的一声，
> 也掉进来。
>
> 出门，风把路灯的声音
> 吹得一会儿黄，一会儿白。
> 我把这一天含在嘴里——
> 一枚硬币：凉的，
> 有别人的指纹。

安静有了味道，蓝有了温度，光与声一起落进电梯；结尾把"这一天"放进嘴里——温度是凉的，触感是别人的指纹。孤独没有出场，但被舌头接住了。

## 二、意象的神经系统：跳跃与黏合

诗允许跳，甚至必须跳，但跳跃要有一根**身体的线索**让读者摸回来。这根线索只有两种：

- **共享感官域**：全诗的意象在同一通道上变奏（都在降温 / 都在失重 / 都在出声）。
- **共享转移**：所有意象都经过同一次通感焊接（都把时间当食物写）。

只靠"主题"作黏合剂的意象是散装道具：键盘、牛肉、电梯、风各摆一个姿势，凑不成一个身体。自觉"跳跃感太强"的诗，先检查缺的是不是这两种线索之一。

意象的地板仍然是**可感**：闭眼能看见、伸手能摸到。地板之上，靠转移给意象通电。动词是意象的关节：一个准确的动词（凝、掉、含）胜过三个形容词。**不解释**——意象一旦被自己翻译成情绪（"我就像那片落叶，漂泊无依"），就死透了；解释的工作留给读者。

## 三、节奏：呼吸与分行

自由诗的节奏不在格律，在三处：**语气的长短、停顿的位置、语义的切分**。

- **行末停顿是最强的停顿。**把重要的词放在行末或行首，别让虚词占住关口。
- **跨行（enjambment）制造悬置。**把语义单元切成两行，读者被拖着走半步，这个"半步"就是张力。
- **长句推进，短句斩截，交替形成变奏。**通篇均匀的句长是节拍器，不是呼吸。
- **韵是意外，不是惯性。**尾韵一连续，句子开始迁就韵，诗滑向顺口溜。
- **出声读。**想换气的地方分行或分节；读起来喋喋不休的地方，砍。

## 四、抒情：反滥调，不反抒情

摒弃的是抒情的**惯性**，不是抒情本身。当代诗的动人方式：

- **冷抒情**：情感藏在陈述的缝隙里。不写"我很想她"，写"手机里她的号码还在，备注没改"。
- **让步与反讽**：主体可疑、可自嘲。"我发誓戒酒——第七次了，瓶子上的灰很厚。"
- **经验的重量**：写父亲，三件具体的小事胜过十行"父爱如山"。
- **转移抒情**：情感不说也不摆，直接通感——见第一节的硬币。

## 五、结尾的几种收法

"升华-点题-感悟"三件套是最深的滥调。可用的收法：

1. **戛然而止**——动作完成即停，不追一句总结。
2. **转向**——最后一节突然看向另一个物，让前面的东西悬在那里。
3. **落在最小处**——结尾缩到最不起眼的细节，重量反而最大。
4. **收紧**——用一个动词把全诗的线收拢。

例（主题：送别，收在第 4 种）：

> 站台广播喊了三遍。
> 你上车，把窗摇下来
> 又摇上去一半。
> 车开时，那一半玻璃
> 替你看着这边。

## 六、声音谱系（校准耳朵用）

以下是参照系，不是模仿对象。用户点名要某路风格时，学其手法（语气、分行逻辑、反讽姿态、转移的方向），不搬运句子：

- **朦胧诗**：北岛的克制与反讽、多多的意象强度、顾城的直觉纯度。
- **第三代口语**：韩东、于坚——口语的庄严，反隐喻传统。
- **语感一路**：张枣的精致、柏桦的语气。
- **九十年代叙事性**：西川、王家新、孙文波——叙事与反讽如何进入诗。
- **近二十年的经验写作**：雷平阳的细节重量、余秀华的直与烈（学其诚，不套其格式）、张二棍、郑小琼。
- **翻译参照**：意象派（庞德、威廉姆斯"不要思想，要事物"）、辛波斯卡的反讽、卡瓦菲斯的语气、佩索阿的多声部。

## 七、陈词滥调黑名单

遇到即拆开重做，或整体换角度：

**自然程式**：明月思乡 / 落叶悲秋 / 风雨后见彩虹 / 蜡烛春蚕 / 梅花坚毅 / 小草顽强 / 大海胸怀 / 星星点亮梦想

**抒情套话**：心灵深处 / 泪水模糊了双眼 / 心中涌起一股暖流 / 无尽的思念 / 岁月的洗礼 / 时间是最好的解药

**抽象大词**：灵魂 / 永恒 / 远方 / 岁月 / 生命（作感叹用时）/ 温柔 / 宿命

**拟人滥调**：风在哭泣 / 星星眨眼 / 花儿微笑 / 大地母亲（作抒情用）

**句式滥调**：我是一只……（身份比喻）/ 像……一样……（贴标签）/ 我要……我要……我要……（排比宣言）/ 有人说……但是我说……（伪思辨）/ 多么……啊！（感叹）

**通感贴纸**：尖锐的蓝色 / 甜美的噪音式乱配 / 每行都串线（转移一旦成为公式，就成了新滥调——通感贵在少而承重）

**替代思路**：不是找"更高级的同义词"（把"悲伤"换成"忧伤"没用），而是回到经验现场跑感官矩阵：这件事真的发生时，它的温度、重量、味道是什么？

## 八、AI 诗的通病（本技能的失败模式，自查时优先排查）

- **白描道具化**：每条规则都合规，但意象是清单上的摆拍，之间只靠主题硬串——这是规则当发动机的必然结果。
- 每节结尾都往上扬——把四个小结尾写成四次升华。
- 抽象名词密度高：一节里"时光、灵魂、远方"占了三行。
- 均匀的抒情段落：行行都美，合起来不知道在说什么——"漂亮的废话"。
- "我"的泛滥：每行都以"我"开头。
- 隐喻过密或通感过密：一行一个串线，读者来不及落脚，转移贬值。
- 晦涩冒充深刻：跳跃没有身体的线索可摸，只剩词的蒙太奇。

好诗的密度来自"物多词少"，但物必须通电：一次承重的转移，胜过十个准确的道具。
