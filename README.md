# modern-poetry · 当代诗歌写作 Skill

帮助 agent 写现代汉语自由诗、修改旧作的技能（Skill），适用于 ZCode 等支持 skills 的编程助手。

审美立场一句话：**主体性为骨架，通感为发动机，规则只除锈**——摒弃浪漫主义滥调（直接抒情喷发、程式化意象、升华式结尾），也反对把写作退化成规则清单的执行：只守规则的诗准确而死。

## 核心设计

1. **主体性（骨架）**——诗里必须有"谁"：一个有位置、有处境、有利害的说话者。动笔先过主体三问（站在哪 / 与物什么关系 / 此刻的利害）。
2. **通感与联觉（发动机）**——想象力的本质是经验在感官通道之间的转移：给声音温度、给颜色重量。每次转移要"接得住"（身体可定位）且"承重"（拆掉诗会塌）。
3. **除锈剂（规则）**——禁滥调、禁升华、禁感叹，只在最后一步做减法，永远不当发动机。

**现代物入诗铁律**：空调、地铁、工卡这类物件不许当布景摆拍，必须经过谁的眼睛、或换算成主体的经验单位、或带着使用痕迹与利害。

## 安装

克隆到用户级 skills 目录（目录名须为 `modern-poetry`，与 skill 的 name 一致）：

**Windows（cmd / PowerShell）:**

```cmd
git clone https://github.com/chaojibai/modern-poetry-skill "%USERPROFILE%\.agents\skills\modern-poetry"
```

**Linux / macOS:**

```bash
git clone https://github.com/chaojibai/modern-poetry-skill ~/.agents/skills/modern-poetry
```

重启会话后自动被发现；说"写首诗""帮我改改这首现代诗"即可触发。

## 用法示例

- 「写一首关于深夜加班的现代诗」（模糊主题，技能会先假设一个主体并说明）
- 「帮我改改这首诗：……」（改诗流程：先找人，再找电，再找锈）
- 「按张二棍的路子写一首」（先精读对应拆解节，学手法不搬句子）

## 方法来源与致谢

技能的审美与工艺建立在对六位当代诗人的文本拆解之上：**张二棍、江非、于坚、翟永明、海男、郑小琼**。各篇全文出处链接见拆解文件末尾，请读原文。

## 声明

- 拆解文件中的诗句引文均极简（每位诗人一至两行）、注明出处，仅用于手法分析与教学对照，版权归原作者所有。
- 本技能生成的诗歌为原创输出：手法（语气、分行逻辑、转移方向、主体位置）可学，任何诗人的句子与标志性意象组合不予挪用。
